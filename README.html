Crypto AI Terminal¶

Quantitative Research Infrastructure

Crypto AI Terminal relie l’observation du marché, une expérience PAPER, la vérité lifecycle et financière, la recherche reproductible et une application opérateur. Le projet sépare les producteurs de faits, les hypothèses Research et les autorités de décision.

SOURCE STATE ≠ DEPLOYED RUNTIME STATE

Un merge, un test vert ou une capture UI ne prouve pas un déploiement. Le burn-in est protégé par #286. Cette documentation n’autorise aucun changement de la machine active.

flowchart TD
    Market[MARKET — observations] --> Paper[PAPER SCIENCE — expérience gouvernée]
    Paper --> PPL[PPL — vérité lifecycle]
    PPL --> FIN[FIN — vérité financière]
    PPL --> Dataset[Dataset Research immuable et identifié]
    Dataset --> Replay[RESEARCH LAB — replay]
    Replay --> Diagnostics[Diagnostics]
    Diagnostics --> Candidates[Candidats et hypothèses]
    Candidates --> Gate[Gate humaine pour une future expérience]
    Gate --> Future[Future epoch gouvernée]
    Paper --> Projection[Projections gouvernées]
    PPL --> Projection
    FIN --> Projection
    Diagnostics --> Projection
    Candidates --> Projection
    Projection --> API[Operator API GET-only]
    API --> App[OPERATOR APP — présentation et preuves]

L’app présente deux espaces : Machine, pour comprendre l’expérience, les services, le portefeuille, les finances, le burn-in et CryptoRadar ; Laboratoire quantitatif, pour consulter datasets, évaluations, diagnostics, candidats et critères des stratégies. Les verdicts et classements proviennent de publications Research identifiées. Le frontend ne les calcule pas et ne possède aucune autorité de trading.
