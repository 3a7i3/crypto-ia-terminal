# Module Family Registry

Mission FAM-01. Flat table of architecturally significant components —
not every Python file, only modules whose family/authority/canonicality a
future agent would otherwise have to re-derive from scratch. Cross-check
against `MACHINE_FAMILY_ARCHITECTURE.md` for the tree view and against
`docs/observability/OBSERVABILITY_MODULE_REGISTRY.md` for the O-01 domain
detail these entries summarize where they overlap (status vocabulary here
is aligned with that document's, extended with STATUS values this mission
needed: `ACTIVE_SOURCE_PATH`, `ACTIVE_PRESENTATION_ONLY`,
`ACTIVE_EXPERIMENTAL`, `ACTIVE_DUPLICATED`).

Every module below has exactly one PRIMARY_FAMILY. RUNTIME_PROOF_REQUIRED
marks a claim about VPS behavior that this source-only mission could not
verify by inspection alone (no SSH was performed).
