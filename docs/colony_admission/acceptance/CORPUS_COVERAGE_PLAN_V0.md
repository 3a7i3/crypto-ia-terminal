Généré par `python -m tests.colony_admission.acceptance.corpus plan` depuis les matrices et `CORPUS_REGISTRY_V0.json`. Ce plan n'est pas une preuve d'exécution : une ligne IMPLEMENTED n'est PASS que dans un rapport de run daté sur un arbre exact.

Règles :

- Une matrice ou ce registre n’est jamais une preuve d’exécution ; PASS/FAIL/NOT_EXECUTED n’existent que dans un rapport de run (report_plugin) sur un arbre exact.
- IMPLEMENTED exige des tests déclarés par case(), qui exercent le point d’entrée public de la matrice et tous les variants énoncés ; une correspondance de nom ou un compteur de tests ne couvre aucun cas.
- name_tag_candidates : tests existants repérés par commentaire ; assertions non vérifiées, non comptés.
- Un verdict NE ou BLOCKED attendu peut être la réussite d’un test négatif ; il ne qualifie jamais le profil ou l’objet concerné.
- BLOCKED exige une raison contractuelle citée ; CONTRACT_NOT_EXECUTABLE est réservé aux cas EXT tant que leur statut contractuel n’est pas amendé.
- Ce registre ne modifie ni les matrices, ni P1/pins/formats/g0, ni accepted=false, ni #286 ACTIVE ; PC2/p1 reste SCIENTIFIC_PROFILE_UNSUPPORTED/NE bloquant.

Rôle des preuves externes : Les 27 cas EF01..EF27 de P4_EXTERNAL_EVIDENCE_CASES_V0.json appartiennent au contrat des formats de preuve externe (P4_EXTERNAL_EVIDENCE_FORMATS_V0.md §7) : ils complètent les scénarios P1 sans les remplacer.
